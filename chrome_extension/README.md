# 🧩 Gemini Nano Studio - Chrome Extension (Manifest V3)

תוסף Chrome חכם ומודרני המאפשר שימוש ב-**Gemini Nano** ישירות מתוך סרגל הצד (Side Panel) ותפריטי קליק ימני בכל אתר אינטרנט.

---

## 🚀 הוראות התקנה מהירה בדפדפן Chrome:

1. **פתח את דף התוספים:**
   - הקלד בשורת הכתובת: chrome://extensions (או לחץ על תפריט 3 הנקודות ➔ תוספים ➔ נהל תוספים).
2. **הפעל 'מצב מפתח' (Developer mode):**
   - הפעל את המתג שנמצא בפינה העליונה (שמאל או ימין בהתאם לשפת הדפדפן).
3. **טען את התוסף:**
   - לחץ על הכפתור **'טען תוסף לא ארוז' (Load unpacked)**.
   - בחר את התיקייה chrome_extension מתוך הפרויקט.
4. **זהו! 🎉**
   - האייקון של Gemini Nano יופיע בסרגל התוספים של כרום.
   - לחץ עליו כדי לפתוח את סרגל הצד (Side Panel), או השתמש בקיצור המקשים Ctrl+Shift+Y (ב-Mac: Cmd+Shift+Y).

---

## ✨ תכונות מרכזיות:
- 📑 **סכם עמוד בלחיצה אחת:** כפתור עליון ששולף את תוכן המאמר הנוכחי ומסכם אותו בצורה מובנית.
- 🔍 **הסבר טקסט מסומן:** סימון טקסט בדפדפן ולחיצה ימנית ➔ *'הסבר טקסט זה עם Gemini Nano'*.
- 🌐 **תרגום ושכתוב:** תרגום ישיר לעברית ושכתוב ניסוחים מקצועיים.
- 🔒 **100% פרטי ומקומי:** פועל ישירות מול מנוע הדפדפן (Prompt API) ללא שליחת מידע לענן.
