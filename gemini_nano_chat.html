תבניות פרומפטים מותאמות אישית:

שלב 1: הפעלת דגלי כרום
chrome://flags/#prompt-api-for-gemini-nano
⬅️ הגדר כ-Enabled
chrome://flags/#optimization-guide-on-device-model
⬅️ הגדר כ-Enabled BypassPerfRequirement
שלב 2: בדיקת הורדת המודל
chrome://components

חפש את Optimization Guide On Device Model ולחץ על Check for update.

שלב 3: דרישת 22GB בכונן C

Chrome דורש לפחות 22GB פנויים בכונן C: כדי לפרוק ולהריץ את המודל.

שלב 4: הפעלת האצת GPU
chrome://settings/system

וודא שההגדרה "השתמש בהאצת גרפיקה כשהיא זמינה" דלוקה.

שלב 5: מצב סוללה בלפטופים

חבר את המחשב לחשמל וודא ב-chrome://settings/performance שמצב חיסכון באנרגיה אינו מגביל את הדף.

שלב 6: פרופיל עבודה / ארגון

חשבונות ארגוניים חוסמים לעיתים את ה-AI. פתח פרופיל אישי ב-Chrome.

שלב 7: שרת ה-Python המקומי
